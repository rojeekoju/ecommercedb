Online Marketplace Database – Project Summary

For this project, I created a database for an online store. The database tracks users, products, inventory, transactions, payments, and reviews.

I followed three steps:

Analysis – I gathered the system requirements.

Logical Modeling – I made an ER diagram using LucidChart.

Normalization – I organized the data to remove redundancy.

Diagram includes six main entities:

User (with Buyer and Seller subtypes)

Product

Inventory

Transaction

Review

Payment

I used crow’s foot notation and showed all relationships, cardinality, and primary keys. I also marked which entities are strong or weak and explained the supertype/subtype relationship.
